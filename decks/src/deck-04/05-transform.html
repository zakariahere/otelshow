transform: rewrite it in flight

transform/redact:
  error_mode: ignore
  trace_statements:
    # client spans carry url.full, server spans carry url.query - redact BOTH
    - replace_pattern(span.attributes["url.full"],  "player=[^&]*", "player=REDACTED")
    - replace_pattern(span.attributes["url.query"], "player=[^&]*", "player=REDACTED")
  log_statements:
    - replace_pattern(log.body, "player \\w+", "player ***")
  • Version one shipped with url.full only. The debug log showed url.query: Str(player=alice) still walking out the door on server spans.
  • Same attribute, different name per span kind — you only find this by reading your own telemetry.
Compliance without code changes is real — but the debug exporter is how you prove it, not the config diff.
