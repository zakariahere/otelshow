04THE MIDDLE OF THE CHAIN

Stamp the origin, ship in chunks

RESOURCE/ENV — THE STAMP

Upserts deployment.environment.name=demo onto every resource passing through — the app never has to know which environment it runs in.

This is where platform metadata belongs: environment, region, cluster. Configured once at the collector, not in every service.

BATCH — THE SHIPPING DEPARTMENT

Collects records for up to timeout: 2s (or a size cap) and forwards them as one batch — fewer, fatter export calls.

Rule #2: always last. Everything after batch would re-split the work; everything before it operates on single records.
