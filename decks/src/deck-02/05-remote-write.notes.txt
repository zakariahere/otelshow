Why remote write and not something OTel-native? Deliberate: this lesson stays inside the Prometheus worldview. Remote write is the API Prometheus admins use for federation and long-term storage today, so nothing here is foreign - the only novelty is WHO is pushing. Mention the component rename wave in collector 0.158 (prometheus_remote_write, otlp_http, resource_detection...): old names are deprecated aliases that log warnings. Pin your collector version and use the new names. The fan-out point matters for later lessons: exporters: [a, b] duplicates the stream - it's how we keep the debug exporter as a microscope in every single branch.
