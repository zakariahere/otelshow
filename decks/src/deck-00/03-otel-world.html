00WHERE WE'RE GOING

One protocol, one local destination

app —— OTLP push (gRPC :4317) → OTel Collector → Tempo · traces Loki · logs Prometheus · metrics
  • OTLP is one wire format that carries all three signals — traces, metrics, logs.
  • The app speaks to exactly one address: the collector. It never learns a backend name.
  • Swap a backend, add a destination, redact a field — all collector config, zero app deploys.
The app's only job becomes emit once, locally — routing is somebody else's YAML.
