Gotcha: Tempo search lags ingestion

  • The ingester flushes to searchable blocks on a timer — freshly shipped traces are stored but not yet findable.
  • We hit it live while verifying: 20 plays looked like 1 kept; the same window re-queried a minute later showed 7.
  • Demo routine: send traffic first, talk through the YAML while it flushes, search last.
  • Matters double next lesson — lag makes tail sampling look broken when it isn't.
