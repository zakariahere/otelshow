05THE EXPORTER

Remote write — an API your admins already know

exporters:
  debug:
    verbosity: detailed
  prometheus_remote_write:  # old name = deprecated alias
    endpoint: http://lgtm:9090/api/v1/write
    tls:
      insecure: true

service:
  pipelines:
    metrics:
      receivers:  [prometheus]
      processors: [memory_limiter, resource/env, batch]
      exporters:  [debug, prometheus_remote_write]
  • Speaks Prometheus's own remote-write protocol — zero new concepts for the Prometheus side.
  • The exporter list is a fan-out: every batch goes to both destinations, in full.
  • 0.158 renamed it: prometheus_remote_write. The old one-word name still works — as a deprecation warning.
One line in a list is all fan-out costs. Same data, two destinations — the debug microscope stays on while real data ships.
