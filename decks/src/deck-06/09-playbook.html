The migration playbook

  1. Stand a collector next to the app. One container, one YAML file.
  2. Point the Java agent at it. Env vars only — the branch 03 diff was five lines and zero code.
  3. Keep the old paths running. Scrape and topics coexist with OTLP; migration is not a cutover.
  4. Enrich, filter, redact centrally. Processors replace the per-app glue code.
  5. Cut backends over one exporter block at a time. The app never learns their addresses.
  6. Only then get fancy — tail sampling, connectors, span metrics.
The collector is not a pipe — it's a platform. Six branches, six diffs, and you can rewind any lesson with git switch.
