00THE MACHINE

The collector is three stages, full stop

receivers→ processors→ exporters
receivers

Get data in — by listening (OTLP on :4317) or by scraping (yes, it can scrape Prometheus endpoints).

processors

Mutate data in flight — batch, enrich, filter noise, redact secrets, sample.

exporters

Ship data out — to one backend or five, per signal, in whatever protocol each speaks.

That's the whole product. This course demonstrates each stage in isolation, one branch each.
