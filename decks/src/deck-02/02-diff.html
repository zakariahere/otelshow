02THE DIFF IS THE LESSON

One git diff, three processors + one exporter

processors:
  memory_limiter:       # ALWAYS first: refuse data before OOM
    check_interval: 1s
    limit_mib: 400
    spike_limit_mib: 100
  resource/env:         # stamp every batch with its origin
    attributes:
      - key: deployment.environment.name
        value: demo
        action: upsert
  batch:                # ALWAYS last: ship in efficient chunks
    timeout: 2s   # long enough to SEE batching happen
  • git diff 01..02 -- otel/ is the whole lesson — nothing else moved.
  • The receiver did not change. The app did not change. Only the middle of the pipe grew.
  • Processors are optional — lesson 01 proved it. Production says otherwise.
Read the comments in the YAML. The two ALWAYS rules are the whole slide — position in the chain is part of the contract.
