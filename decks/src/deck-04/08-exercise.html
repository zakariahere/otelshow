Break it on purpose: swap drop and mutate

  1. In otel/otel-collector.yaml, move filter/noise after transform/redact in the traces pipeline.
  2. docker compose restart otelcol — bind-mount events don't propagate, restart is the only reload.
  3. Send traffic. The output looks… identical. So what changed?
  4. The transform now runs its regexes over every actuator span that was about to die — work you pay for, results nobody sees.
  5. Put it back. Order is invisible in the output and very visible in the CPU bill.
Correctness survives many orderings — cost doesn't. Drop first, then mutate what's left.
